Claude Code Chrome Bridge

Đang kiểm tra…
Bridge không trả lời ở cổng trong URL trên. Cổng đang dùng nằm trong ~/.ccchrome.json (Windows: %USERPROFILE%\.ccchrome.json), hoặc chạy /ccchrome status trong Claude Code.
Chưa cài bridge? Xem README — install.sh dựng dịch vụ nền và in sẵn URL để dán vào ô trên.
